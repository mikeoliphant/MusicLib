This is pretty specific to my needs, but I'm making it publically available in case any of the bits are useful to anyone.

I use it to play music on my Android TV from a USB drive connected to my router (which only supports an ancient version of SMBv1).

It displays song information, and pulls background images based on the song title from https://unsplash.com.

It also runs a little http server that displays song information and a button to skip to the next song.
